# Khanductor

> **Upstream-only Khan Academy example — NOT an HSK AI feature.** Khanductor, its hourglass form, BOY/MOY/EOY testing, district assessment roles and rules below belong to Khan Academy's assessment product. Do not add a Khanductor-style HSK AI proctor, claim a benchmark feature exists, or replace the existing Panda/other lesson characters. Keep these **five source images** as historical teaching examples about the separation of independent assessment and hints; they are not HSK AI art or final screens. Consult <a href="./?path=/docs/design-guidelines-components-characters-hsk-ai-characters--docs">HSK AI characters</a> and the actual exercise reveal/scoring code instead.

**Applicable HSK AI principle:** A task requiring independent answers should not leak hints or answers through mascot dialogue. The app's existing answer feedback must still work after a confirmed evaluation; do not hide the character's correct/incorrect reactions as a substitute for assessment integrity.

<NeutralBadge label="AI assessment proctor" />

Khanductor is an AI persona specifically designed for the formal assessment product. While Khanmigo supports daily learning, Khanductor serves as a neutral proctor during standardized benchmark windows.

## <Do /> When to use

The choice to use Khanductor is determined by the need to provide a neutral, non-directive presence within the assessments product where independent student performance must be preserved.

| Use when | Example use |
| --- | --- |
| Administering Beginning-of-Year (BOY), Middle-of-Year (MOY), or End-of-Year (EOY) benchmark assessments | A student completing a district-mandated "Algebra Assessment" at the start of the semester. |
| Prompting students to explain their logic without hints or corrections | Asking a student, "How do you know?" or "Does this step make sense?" after an input. |

## <Dont /> When NOT to use

| Don’t use when | Recommended alternative | Rationale |
| --- | --- | --- |
| Supporting teachers or admins | Khanmigo | Do not use Khanductor for teachers or admins. Khanmigo is the sole AI partner for educators to answer questions and provide information. |
| Running standard quizzes or unit tests | No mascot | Khanductor is not for standard classroom quizzes or unit tests. It is strictly reserved for the specialized assessment product. |
| Students are in daily practice or learning paths | Khanmigo | Do not use for daily learning paths where students need active "Learning Coach" support and Socratic hints. |
| Assigning or displaying the Gap Finder feature | Khanmigo | Gap Finder is an informal assessment feature. It is not the main Assessment product and should therefore not be using Khanductor. |

## Appearance and scale rules

### Proctor persona

Khanductor uses an hourglass-inspired shape to signal a neutral "proctoring" state, distinguishing it from the supportive hexagonal "coach" persona. Khanductor should not have any accessories — its neutrality depends on staying visually plain.

<img src={appearanceAndScaleRules1Img} alt="Appearance and scale rules 1" />

### Explain your thinking scale

Khanductor maintains a consistent, large scale within the chat frame when active.

## Placement

### Question state

Khanductor is not seen on the question screen while the student is working to ensure independent performance.

<img src={placement1Img} alt="Placement 1" />

### Explanation state

Khanductor only appears once "Explain your thinking" is introduced, positioned within the chat frame to ask follow-up questions.
